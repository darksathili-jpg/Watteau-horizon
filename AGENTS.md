# Watteau Horizon — directives de production

## Mission
Jeu web d’orientation post-bac du lycée Watteau de Valenciennes. Univers urbain original, compagnon Antoine, données officielles, GitHub Pages. Phaser/React/TypeScript à confirmer par prototype.

## Autonomie
- Exécuter les lots autorisés jusqu’à livraison testée, sans demander de feu vert entre tâches ordinaires.
- Si une dépendance manque, noter le blocage et poursuivre les tâches indépendantes. Deux tentatives ciblées maximum avant changement d’approche.
- Ne jamais contourner les permissions. Demander une décision seulement pour risque juridique, sécurité, coût supplémentaire, action destructive ou changement majeur de périmètre.
- Ne pas annoncer de travail en arrière-plan ni de livraison sans preuve.
- Maintenir PLANS.md et un journal de preuves; lire uniquement les documents utiles à la tâche.

## Qualité
- Sources officielles datées, provenance par champ critique, licences vérifiées; aucune donnée inventée. Signaler les inconnues et les contradictions. Ne pas présenter un score comme prédiction d’admission.
- Orientation non déterministe, accessible sans jeu ni IA; données personnelles locales par défaut, aucun secret dans le client.
- Les maquettes générées ne sont pas des références architecturales certifiées. Utiliser des photographies autorisées pour les décors; ne pas reproduire de personnes identifiables ni de plans sensibles. Ne pas publier les photos sans droits.
- Ne pas modifier les références visuelles ou tests pour masquer un échec. Captures réelles, comparaison visuelle, tests de collisions et d’animation.
- Tests unitaires, E2E, accessibilité, données, compilation et sécurité avant livraison; conserver les résultats réels.
- Ne pas publier une version institutionnelle sans autorisation appropriée. GitHub Pages uniquement.

## Exécution
Commencer par un prototype vertical jouable et une chaîne de données minimale vérifiable. Étendre seulement après réussite des contrôles. Travailler par lots cohérents et commits traçables. Les choix provisoires doivent être documentés.
